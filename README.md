# PR Practice

初めてのPull Requestを練習するためのリポジトリです。

## これは何？

このリポジトリは、GitHub上でのPull Requestの作り方を学ぶための練習場です。

## 使い方

1. ブランチを作る
2. 変更をコミットする
3. Pull Requestを開く
4. マージする

## 貢献方法

1. リポジトリをフォークまたはクローンする
2. わかりやすい名前でブランチを作成する(例: `fix/typo-in-readme`)
3. 変更をコミットする
4. Pull Requestを開き、変更内容を簡潔に説明する

## ステータス

- [x] リポジトリ作成
- [ ] 最初のPRをマージ
